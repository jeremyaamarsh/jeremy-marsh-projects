## Projects

#### Below is a selection of projects from my data science portfolio. Each project includes a short summary and a link to the full code and documentation.

### Airline Delay Classification  

Summary: Built a full machine-learning workflow to classify whether a given airport and airline experienced significant arrival delays during a specific month. Includes data cleaning, feature engineering, pipelines, hyperparameter tuning, and model evaluation. Random Forest achieved perfect accuracy due to highly separable operational features.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/airline-delay-classification

### Kia/Hyundai Auto Theft Surge Analysis  

Summary: RStudio project analyzing the surge in Kia/Hyundai thefts across U.S. cities. Integrated multiple datasets, built treemaps, stacked bars, trend lines, and city-level comparisons. Findings show thefts are make-specific and concentrated in a small number of cities. Includes full R scripts and a PDF executive briefing.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/kia-hyundai-theft-analysis

### Loan Approval Model Selection & Hyperparameter Tuning  

Summary: Compared KNN, Logistic Regression, and Random Forest using pipelines and GridSearchCV. Logistic Regression with tuned hyperparameters achieved the best cross-validation and test accuracy. Demonstrates multi-model search and structured ML workflow.  

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/loan-approval-model-selection

### Netflix Titles Exploratory Data Analysis

Summary: Performed EDA on Netflix’s catalog to understand genre distribution, maturity ratings, and movie duration patterns. Built countplots, boxplots, and bivariate visuals. Findings show Netflix emphasizes mature content while maintaining strong family-friendly categories.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/netflix-eda-visualization

### MovieLens Recommender System (SVD)

Summary: Built a recommender system by comparing movies to one another, using collaborative filtering with Surprise’s SVD algorithm. Used the model’s learned movie features to identify similar titles. Includes a search function that returns top matches based on partial title input.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/movielens-recommender-system

### MNIST CNN Classifier (PyTorch)

Summary: Built and trained a convolutional neural network to classify handwritten digits. Achieved ~98–99% accuracy. Demonstrates full deep-learning workflow including data loading, model architecture, training loop, evaluation, and visualization.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/mnist-cnn-classifier

### NYC Taxi Trip Duration Prediction

Summary: Predicted taxi trip duration using engineered time-based and geographic features. Random Forest explained ~73% of variance. Demonstrates feature engineering (Haversine distance), regression modeling, and residual analysis.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/nyc-taxi-trip-duration

### U.S. Retail Sales Time Series (ARIMA)

Summary: Reshaped wide-format retail sales data into a monthly time series and built an ARIMA model to forecast future sales. Shows trend analysis, forecasting, and evaluation against actual data.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/us-retail-time-series

### White House Visitor Log Analysis

Summary: Cleaned and merged multiple inconsistent CSV files into a unified dataset. Built visuals showing daily and monthly visitor patterns, category breakdowns, and operational spikes. Demonstrates ingestion, harmonization, feature engineering, and visualization.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/white-house-visitor-analysis

### MLB Attendance Analysis

Summary: Explored Dodgers 2022 home game attendance to identify factors influencing turnout. Found that promotions and opponent matchups significantly affect attendance. Demonstrates EDA, visualization, and simple insights from real-world sports data.

Link: https://github.com/jeremyaamarsh/jeremy-marsh-projects/tree/main/projects/mlb-attendance-analysis
