# MLB Attendance Analysis

## Project Overview
This project looks at attendance for Los Angeles Dodgers home games during the 2022 season. I wanted to see what actually affects turnout such as the day of the week, or who they’re playing, weather, and any promotions. The goal was to explore the data and pull out simple insights without overcomplicating it.

## Goals and Objectives
- Get familiar with the dataset and make sure it’s usable  
- Look at how attendance changes under different conditions  
- Figure out which factors seem to matter most  
- Summarize the findings in a clear, simple way  

## Techniques and Technologies Used
- Python  
- Pandas for exploring and cleaning the data  
- Matplotlib and Seaborn for charts  
- Jupyter Notebook for running and documenting the analysis  

## Summary of Conclusions
- Some days of the week consistently draw bigger crowds  
- Opponent matchups make a noticeable difference  
- Promotions like fireworks and bobbleheads help boost attendance  
- Weather plays a smaller role, but it still shows up in the data  
- Overall, scheduling and promotions appear to be the most reliable drivers
